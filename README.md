# InOut

InOut is a social calorie tracker for what you eat and what you burn. Users can log meals and workouts, view their daily calorie balance, and share their progress with friends.

## Planned Core Features

- Email authentication and user profiles
- Meal logging with calories and macronutrients
- Workout logging with MET-based calorie estimates
- Daily calories-in, calories-out, and net balance
- Social feed for meal and workout posts
- Follow, like, and comment interactions
- Profile page and weekly summary

## Optional Features

- Step counter integration
- Challenges and streaks
- Friend groups
